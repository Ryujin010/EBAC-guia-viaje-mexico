## 📖 Descripción

Página web con una guía de destinos turísticos de México, pensada para presentar información de forma clara y atractiva, la cual presenta también revisiones y pruebas para a accesibilidad web y tecnologías de asistencia para cualquier tipo de persona hechas con WAVE.

## 🛠️ Tecnologías

- **HTML5**
- **CSS3**

## ✨ Características

- Secciones por destino turístico
- Diseño visual atractivo con CSS
- Navegación sencilla entre secciones

## 🚀 Instalación y uso

Clona el repositorio:

```bash
git clone https://github.com/Ryujin010/EBAC-guia-viaje-mexico.git
cd EBAC-guia-viaje-mexico
```

Luego:

1. Abre el archivo `index.html` en tu navegador (doble clic), o
2. Usa la extensión **Live Server** de VS Code: clic derecho sobre `index.html` → *Open with Live Server*.

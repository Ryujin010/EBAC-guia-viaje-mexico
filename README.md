# Guía de Viaje México

Sitio web de 5 páginas sobre destinos, hospedaje y gastronomía de México,
con mejoras de accesibilidad web.

## Accesibilidad aplicada
- Idioma principal (`lang="es"`) y texto en otros idiomas (`lang="en"`)
- HTML semántico y enlace "Saltar al contenido"
- Textos alternativos (`alt`) en las 14 imágenes
- Formularios con `label` y `for`
- Contraste revisado (WCAG AA) en modo claro y oscuro
- Roles ARIA y `aria-label`
- Validado con WAVE
